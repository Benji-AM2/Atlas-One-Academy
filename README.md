# Atlas One Academy Website

A multi-page, responsive school website built for **Atlas One Academy** (Preschool through Junior High School).

## 🚀 Features
- **Multi-page Architecture**: Clean separation of pages for Home, About, Classes, Gallery, Admissions, Teachers, and Contact.
- **Responsive Design**: Optimized for desktop, tablet, and mobile viewing.
- **Interactive Gallery**: Filterable photo categories (Events, Sports, Academics, Facilities, etc.).
- **Consistent Styling**: Unified external CSS stylesheet for smooth branding across all pages.

## 🛠️ Built With
- HTML5
- CSS3 (Flexbox & Grid, CSS Variables)
- Vanilla JavaScript (for gallery filters)
- Google Fonts (Merriweather & Roboto)
